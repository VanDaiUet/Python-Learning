# Tài liệu học chính thức

Các đường dẫn dưới đây được đối chiếu ngày 11/09/2026. Ưu tiên đọc đúng phần đang học; không cần đọc hết mọi tài liệu. Giáo trình tiếng Việt trong thư mục này là nội dung tự biên soạn; các nguồn giúp tra cứu API và mở rộng.

| Giai đoạn | Nguồn | Dùng để làm gì |
|---|---|---|
| Python | [Python Tutorial](https://docs.python.org/3/tutorial/) | Tra cú pháp, cấu trúc dữ liệu, module, lỗi và lớp |
| Môi trường | [venv](https://docs.python.org/3/library/venv.html) | Hiểu môi trường riêng và cách chọn interpreter |
| Kiểm thử | [unittest](https://docs.python.org/3/library/unittest.html) | Viết test bằng thư viện chuẩn |
| Kiểm thử dự án | [pytest Getting Started](https://docs.pytest.org/en/stable/getting-started.html) | Lựa chọn bổ sung khi làm dự án |
| Tính toán | [NumPy beginner guide](https://numpy.org/doc/stable/user/absolute_beginners.html) | Array, shape, axis, indexing và phép tính |
| Dữ liệu | [pandas tutorials](https://pandas.pydata.org/docs/getting_started/intro_tutorials/index.html) | Đọc bảng, chọn dòng, tạo cột, tổng hợp và ghép bảng |
| Biểu đồ | [Matplotlib tutorials](https://matplotlib.org/stable/tutorials/index.html) | Vẽ và chú thích hình phục vụ phân tích |
| ML | [scikit-learn Getting Started](https://scikit-learn.org/stable/getting_started.html) | fit, predict, preprocessing, Pipeline và đánh giá |
| Đánh giá ML | [Common pitfalls](https://scikit-learn.org/stable/common_pitfalls.html) | Nhận biết rò rỉ dữ liệu và tránh fit trên dữ liệu đánh giá |
| Deep Learning | [PyTorch tutorials](https://docs.pytorch.org/tutorials/intro.html) | Tensor, dữ liệu, autograd và vòng huấn luyện |
| Cài PyTorch | [Get Started](https://pytorch.org/get-started/locally/) | Chọn lệnh theo máy và khả năng CPU/CUDA |
| LLM/NLP | [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1) | Đọc sau khi có Python và nền tảng Deep Learning |
| API | [FastAPI Tutorial](https://fastapi.tiangolo.com/tutorial/) | Tạo endpoint, schema và kiểm thử ứng dụng |

Tài liệu `/3/` hoặc `/stable/` có thể thay đổi phiên bản. Khi ví dụ không phù hợp môi trường, xem phiên bản gói đang dùng và chuyển tài liệu về phiên bản tương ứng. Không sao chép một lệnh cài GPU chỉ vì nó xuất hiện trong một bài hướng dẫn.
