# Bài làm của bạn

Theo lịch hiện tại, tạo thư mục `4_tuan/ngay_01` đến `4_tuan/ngay_28` khi học đến ngày tương ứng. Lưu mã, kết quả nhỏ và nhật ký ở đó; sản phẩm đặt trong `4_tuan/S1` đến `4_tuan/S4`.

Các thư mục `tuan_01` đến `tuan_40` và `du_an/P01` đến `du_an/P06`, nếu bạn đã tạo, thuộc bản đầy đủ để học tiếp. Mỗi dự án nên có README hướng dẫn chạy từ đầu. Không lưu khóa API hoặc dữ liệu nhạy cảm vào mã nguồn.

Bạn sửa trực tiếp các file trong `thuc_hanh/bai_tap` khi làm tám bộ bài tập trong ngày 1–4 của lịch mới.
